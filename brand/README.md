# شعار نَسَق

الرمز الحالي: **ورقتان بحروف الاسم ومعينان ذهبيان** (صمّمه صاحب اللوح، ٢٠٢٦-٠٩).

| الملف | الاستخدام |
|---|---|
| `nasaq-mark-color.svg` | الأصل — الألوان الرسمية، على الخلفيات الفاتحة |
| `nasaq-mark-ink.svg` | أحادي داكن (طباعة، أختام) |
| `nasaq-mark-light.svg` | على الخلفيات الداكنة (للمطبوعات فقط) |
| `nasaq-2a-mark-color 2.svg` | ملف Illustrator الأصلي الذي صُدّر منه الرمز |
| `nasaq-2a-mark-*.svg` | الرمز السابق (وحدتان ونقطة) — للأرشيف |

الألوان: Teal ‎`#174C4F` · Mid Teal ‎`#2F6F6B` · Saffron ‎`#D6A84F` · Ivory ‎`#F7F6F2`

**قاعدة صارمة:** داخل المنصة لا تتغيّر ألوان الشعار في أي طابع أو وضع. على الخلفيات الداكنة يجلس على قرص عاجي (`nasaq-theme.css`) بدل تغيير ألوانه.

**عند تغيير الشعار:** عدّل المسارات في `nasaq-brand.js` وحده (تعريف واحد تستعمله كل الصفحات)، ثم أعد توليد `icons/*.png`، وارفع رقم `CACHE` في `sw.js`.
